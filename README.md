# إنجاز — نظام إدارة المهام

نسخة MVP عربية RTL قابلة للتشغيل مباشرة من المتصفح. لا يوجد خادم خلفي في هذه النسخة؛ تُحفظ المهام وسجل العمل والمرفقات في `localStorage` الخاص بالمتصفح كي تعمل التجربة كاملةً محلياً.

## التشغيل

يتطلب التشغيل Node.js (إصدار 20 أو أحدث) وnpm:

```powershell
npm install
npm run dev
```

ثم افتح العنوان الذي سيظهر في الطرفية، وعادةً يكون `http://localhost:5173`.

للتشغيل من دون تثبيت الاعتمادات في المشروع يمكنك استخدام أي خادم static محلي. لا تفتح `index.html` بالنقر المزدوج؛ الأفضل استخدام خادم محلي حتى تعمل وحدات JavaScript بصورة موثوقة.

## ما يتضمنه الـMVP

- لوحة مدير بمؤشرات إجمالي المهام، قيد التنفيذ، المكتملة، والمتأخرة.
- إنشاء مهمة بعنوان ووصف وأولوية وحالة وتاريخ بدء/استحقاق وإسنادها لعدة موظفين.
- عرض المدير لكل المهام، وعرض الموظف للمهام المسندة إليه فقط.
- تحديث حالة المهمة، سجل عمل بالساعات، ومرفقات ملفات أو صور.
- صفحة تفاصيل متكاملة تشمل النشاطات، السجل، المرفقات، والمكلّفين بالمهمة.
- قائمة فريق بأدوار مدير وموظف، وتجربة تبديل مستخدم سريعة من الشريط الجانبي للتجربة.
- تصميم نظيف ومتجاوب بالكامل واتجاه عربي RTL.

## حدود النسخة الحالية

هذه نسخة واجهة وظيفية محلية وليست نظاماً متعدد المستخدمين على خادم. للانتقال إلى إنتاج حقيقي، الخطوة التالية هي إضافة API وقاعدة بيانات ومصادقة وتخزين ملفات خارجي وتنبيهات فعلية.
